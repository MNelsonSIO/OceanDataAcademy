# OceanDataAcademy

This is a repository of resources for beginners in physical oceanography data analysis. 


Developer notes:

/assets/ contains things like images

/docs/ contains the markdown files (.md) which will serve as webpages, e.g., a blog post with embedded code explaining how to open a Jupyter file

/code_resources/ is for dumping useful or instructional code files (e.g., Aurora's nice MATLAB files!)
